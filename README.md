# Bank Management System (C++)

A simple **Bank Management System** implemented in C++ using **Object-Oriented Programming** concepts such as **Classes, Inheritance, and Exception Handling**.  

This project demonstrates how banking operations like **deposit, withdrawal, and balance checks** can be simulated in C++.

---

## Features
- Create new accounts (Savings / Current)  
- Deposit money into an account  
- Withdraw money with balance validation  
- Check balance & display account details  
- **Exception handling** for invalid transactions  
- Demonstrates **OOP principles** (Classes, Inheritance, Polymorphism)
